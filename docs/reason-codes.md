# Reason code conventions and core catalog

Reason codes are stable machine-readable explanations. New codes may be added
without breaking schema 1.0; renaming/removing a code is a contract change.
The lists below document the principal frozen/domain codes, not an exhaustive
runtime registry. Validation enforces uppercase `^[A-Z][A-Z0-9_]{1,63}$`, 1–32
unique codes per transport object. API/persistence/auth/idempotency paths may add
specific codes alongside this catalog; use tests/source search before treating a
missing list entry as unsupported.
